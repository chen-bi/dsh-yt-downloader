DeepSeek Harness Plugin

视频下载器

侧边栏常驻的下载面板：粘一条链接 → 选画质（144p–4K）→ 下载视频，或只抽音频。

yt-dlp · YouTube / B站 / X / TikTok / 微博 / Vimeo / 直链 …

GitHub 仓库 安装说明

1000+ 站点

背后是 yt-dlp，视频页、直播回放、直链 .mp4/.mp3/.m3u8 都认。

画质任选

144p 到 4K，优先 H.264；只有一体格式时直接下；仅音频转 MP3。

进度实时

速度、剩余时间、合并状态都在队列里，下完可一键打开文件或文件夹。

代理友好

默认跟随 Windows 系统代理，也能手填；代理没开会直接提示，不闷头超时。

安装

git clone https://github.com/chen-bi/dsh-yt-downloader.git
cd dsh-yt-downloader
node scripts/setup-ytdlp.mjs   # vendor/ 不随仓库走，装一次 yt-dlp

然后在 DSH 里 plugin_manager → install_bundle 指向该目录，刷新页面。

依赖：Python 3（优先 uv 装的）、ffmpeg（找 ~\.pyffmpeg\bin 或 vendor 里的），都不需要全局安装 yt-dlp。

接口

方法路径用途
GET/api/ytdl/state引擎状态、代理、下载目录、队列
POST/api/ytdl/probe{url} → 标题/封面/画质列表
POST/api/ytdl/download{url, mode, formatId} → 建任务
GET/api/ytdl/jobs队列与进度
POST/api/ytdl/cancel{id} 取消

说明

  • 只接受 http(s) 链接；本地路径和其他协议一律拒绝。
  • 下载任务在内存里，DSH 重启后队列清空（文件还在）。
  • 受限内容（付费 / 会员 / DRM）下不了；自己看没问题，二次分发请遵守平台条款。
